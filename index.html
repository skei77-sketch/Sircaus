Arquitectura de Datos del Sistema

$$\text{Manilla NFC} \longrightarrow \text{MFRC522} \longrightarrow \text{ESP32 (Wi-Fi)} \longrightarrow \text{Base de Datos (Firebase / SQL)} \longrightarrow \text{App Móvil de Padres}$$
01 Inducción Pasiva: La manilla pasa por el campo magnético de 13.56 MHz del lector MFRC522.
02 Validación Local: El ESP32 procesa el código UID serial mediante el bus de datos SPI.
03 Sincronización Cloud: Vía Wi-Fi HTTP/MQTT, el ESP32 envía la asistencia a la base de datos centralizada.
04 Notificación Push: La App móvil para acudientes recibe una alerta instantánea en su smartphone.

HARDWARE Y MAPPING DE PINES

Ficha Técnica Interactiva

Haz clic en cada tarjeta para desplegar el mapeo exacto de pines y las especificaciones del circuito:

ESP32 DevKit Microcontrolador

Procesamiento central con antena Wi-Fi e interfaz SPI.

  • Frecuencia CPU: 240 MHz Dual Core
  • Memoria SRAM: 520 KB
  • Módulo Inalámbrico: Wi-Fi + Bluetooth 4.2 BLE

Lector MFRC522 Conexión SPI

Módulo lector RFID/NFC operando a 13.56 MHz.

  • SDA / SS: Pin GPIO 5
  • SCK: Pin GPIO 18
  • MOSI: Pin GPIO 23
  • MISO: Pin GPIO 19
  • RST: Pin GPIO 4

LEDs Indicadores GPIO 25 / 26

Leds de respuesta rápida para estado de validación.

  • LED Verde (Acceso Permitido): Pin GPIO 26
  • LED Rojo (Acceso Denegado): Pin GPIO 25
  • Cátodos (-): Conectados a GND

Buzzer Activo GPIO 33

Emisor de tonos audibles tras el escaneo.

  • Ánodo (+): Pin GPIO 33
  • Cátodo (-): GND
  • Patrón de sonido: Tono continuo (2000Hz) en éxito

Comunicación por Bus SPI

El módulo MFRC522 transfiere la lectura del código UID único hacia el ESP32 mediante el protocolo serial síncrono SPI de alta velocidad.

  • Inducción Magnética: La antena de 13.56 MHz alimenta el tag pasivo de la manilla.
  • Respuesta Inmediata: Los GPIOs de salida activan el LED verde y la señal sonora en menos de 100ms.
DESCARGA Y FIRMWARE

Código C++ y Diagramas de Conexión

Firmware estructurado para el IDE de Arduino y simuladores en línea como Wokwi:

firmware_sircaus_esp32.ino 
#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN    5
#define RST_PIN   4
#define LED_VERDE 26
#define LED_ROJO  25
#define BUZZER    33

MFRC522 rfid(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(115200);
  SPI.begin();
  rfid.PCD_Init();
  
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_ROJO, OUTPUT);
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  // Detectar si hay una nueva manilla NFC presente
  if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) return;
  
  // Procesar lectura del UID de la manilla
  tone(BUZZER, 2000, 100);
  digitalWrite(LED_VERDE, HIGH);
  delay(1000);
  digitalWrite(LED_VERDE, LOW);
}
